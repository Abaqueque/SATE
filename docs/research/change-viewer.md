# Showing real change in SPHEREx observations

Research and code audit, 15 November 2026. Recommendation for SATE's faint-mover search: compare two selected observing windows on a fixed background-star coordinate grid, using linked side-by-side views and eventually blink plus a validated difference image. Preserve individual exposures as evidence. Zoom helps inspection; it cannot supply missing signal, recover masked pixels or make unlike measurements comparable.

## Evidence that changes the implementation

1. **Match the measurement, not just a dropdown label.** SPHEREx's per-pixel passband varies across the detector. IRSA explicitly describes WCS-WAVE as a visualization approximation and directs scientific use to CWAVE and CBAND calibration. SATE currently selects midpoint-defined channel bins and uses WCS-WAVE; two accepted exposures can have different centre wavelengths and different valid spatial coverage. Broad All/Mix views are browsing modes, not controlled temporal comparisons. [IRSA data products](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-products/).
2. **Match point-source shape before interpreting subtraction.** The effective PSF varies with location and wavelength. Registered coordinates alone do not match the shapes or detector sampling of stars. Use the local ePSF, including pixel phase and native-pixel integration, to model or homogenize exposures and inspect residuals on comparison stars. [IRSA ePSF tutorial](https://caltech-ipac.github.io/irsa-tutorials/spherex-psf/).
3. **Use a common valid footprint and fixed display scale.** Compare only pixels supported at both dates, retaining quality/uncertainty provenance. Missing pixels must not appear as fading sources. Background estimation should exclude sources. Nonlinear denoising and gap interpolation belong to optional display processing, never the detection/measurement input. These are recommendations from the code/data audit; the current viewer has shared scale and WCS alignment but does not implement the full pairwise science treatment.
4. **Stack within motion-safe windows.** Time-resolved WISE coadds demonstrate why separate epochs can outperform a single deep all-time image for motion searches. Their cadence and passbands are not transferable settings for SPHEREx. Select a stacking window using allowed motion smear, sampling, coverage and response compatibility. Align on background stars; centring each exposure on the moving target would remove the motion being sought. [Meisner et al., time-resolved WISE coadds](https://arxiv.org/abs/1710.02526), [Planet Nine search with WISE coadds](https://arxiv.org/abs/1712.04950).
5. **Add a difference diagnostic after validation.** Background-matched, registered and PSF-matched differences can isolate movers and variables. Proper subtraction methods have assumptions, including sampling and noise, which must be tested for these undersampled observations. Do not treat a generic ZOGY implementation as automatically optimal for this data. [Zackay, Ofek & Gal-Yam](https://arxiv.org/abs/1601.02655).

The IRSA “source discovery” notebook subtracts different detector bands to find unusual colours. It is useful for understanding reprojection and masks, but is not evidence that the same recipe validates temporal variability. [Notebook](https://caltech-ipac.github.io/irsa-tutorials/spherex-source-discovery-tool-demo/).

## Practical order for this project

- Ship the requested dual viewer, independent top/bottom time markers, linked zoom/pan and preloading. Keep both exposure dates and real centre wavelengths inspectable. This improves the mechanics of comparison without claiming automatic detection.
- Introduce an explicit scientific comparison pair: CWAVE/CBAND response compatibility, shared valid support, local background-star registration diagnostics, local ePSF modelling/matching and one fixed stretch. Make insufficient overlap a visible result rather than filling gaps.
- Add blink and a noise-aware difference pane based on those validated data. Test static stars, masked/saturated sources, changing backgrounds and injected motion/brightness changes; use injections only as labelled validation fixtures.
- Require independent repeat evidence and catalog/ephemeris checks before promoting a candidate. A third epoch is a useful confirmation target, not a universal proof of novelty. [NASA Backyard Worlds](https://science.nasa.gov/citizen-science/backyard-worlds-planet-9/) illustrates the usefulness of flipbooks and artifact vetting.

## Local evidence and limits

The earlier known-Mira example, [WWV2004] J1502099+593125, provides a bounded demonstration of large real brightness change. The saved registered FITS products were rechecked on 15 November: common valid masks and complete target/comparison apertures pass; the late/early aperture-sum ratio is 0.2081, while two comparison patches yield 0.9990 and 1.0037. This recheck used the saved registered products, not a new download or an independent rerun of the complete raw reduction. One comparison patch is a blended pair. The previously recorded individual spectral-pair ratios are 0.2368 and 0.1707. These are display-validation diagnostics, not precision calibrated photometry.

Its native sampling is 6.15 arcsec/pixel and the recorded PSF FWHM is about 7.53 arcsec; the 1.5 arcsec output grid only resamples those measurements. Strong brightness variation is a positive-control example; it does not establish sensitivity to Planet Nine or faint brown-dwarf motion. The general cell viewer's coadd remains optional ±3-hour, close-wavelength display processing, not the validated scientific comparison described above.
